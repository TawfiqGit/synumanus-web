Questions fréquentes

Développement mobile

Combien coûte le développement ?

Le devis est établi après cadrage, sur un périmètre précis. Les principaux facteurs : nombre d’écrans, règles métier, intégrations et plateformes.

Comment suivre l’avancement ?

Toutes les deux semaines, vous recevez une version à tester sur votre téléphone et un point sur les priorités suivantes.

À qui appartient le code ?

À vous. Le code source, les comptes des stores et les données sont à votre nom.
